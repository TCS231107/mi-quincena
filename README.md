# Mi Quincena

App de presupuesto por periodo de pago (quincenal, semanal, mensual o diario): salario, gastos fijos, ahorro automático, metas, gastos variables y estado de cuenta por periodo (con descarga en PDF).

App estática de un solo archivo (`index.html`). Los datos se guardan en el `localStorage` del navegador.

## Ejecutar

```bash
python3 -m http.server 5173
```

Luego abre http://localhost:5173/index.html
